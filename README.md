# Bacana Games

Site com as minhas avaliações dos jogos de PC que já joguei, feito como atividade da disciplina de Fundamentos da Programação Web (ADS - PUC Paraná).

**Acesse:** https://flog-22.github.io/bacana-games/

## Funcionalidades
- Catálogo de jogos com capa, nota de 0 a 10 e categorias
- Filtro por categoria, busca por nome, ordenação por nota e botão de jogo aleatório
- Página de cada jogo gerada por JavaScript, com sinopse, prints, opinião e barra de nota
- Formulário de sugestão com validação de todos os campos (expressões regulares) e página de resultado via método GET
- Menu responsivo (hambúrguer no celular)

## Tecnologias
HTML5, CSS3 e JavaScript puro, sem frameworks.

## Créditos
As capas e os nomes dos jogos pertencem aos seus respectivos criadores e empresas e são usados apenas para fins educacionais.# bacana-games
